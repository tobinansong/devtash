## Commands

- `npm run dev` — start dev server (Turbopack, Next.js 16)
- `npm run build` — production build
- `npm run start` — serve production build
- `npm run lint` — run ESLint (flat config, ESLint 9)



## Important

This project uses Next.js 16 which has breaking changes from earlier versions. Always read the relevant guide in `node_modules/next/dist/docs/` before writing code that touches Next.js APIs.
